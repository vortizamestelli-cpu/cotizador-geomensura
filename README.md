# Cotizador de Movimiento de Tierras - EDOS SpA

Aplicación web desarrollada en Streamlit para el cálculo operativo, margen comercial y generación de propuestas formales de movimiento de tierras.

## Características
- Cálculo de volúmenes con factor de esponjamiento.
- Presupuesto de excavación, transporte y mitigaciones.
- Generación de documento formal de propuesta comercial.
